# Terraform on Azure – Hands-On | Certification-Ready | Real-World

This repository is a **complete hands-on Terraform learning journey on Azure**, covering **Infrastructure as Code fundamentals**, **advanced Terraform concepts**, and **certification-aligned topics**, all backed by real Azure implementations.

---

## 🎯 What This Repository Covers

- Terraform from **zero to advanced**
- Azure infrastructure provisioning using Terraform
- Real-world Terraform usage patterns
- HashiCorp Terraform Associate (003) aligned
- Deep focus on **state, modules, governance, and scaling**

---

## 🧰 Tech Stack

- **Cloud:** Microsoft Azure
- **IaC Tool:** Terraform
- **Editor:** VS Code
- **CLI Tools:** Azure CLI, Git
- **State Backend:** Azure Storage Account
- **Governance:** Sentinel Policies (Terraform Cloud)

---

## 📂 Repository Structure

The repository is organized **concept-by-concept**, matching how Terraform is used in real enterprise environments:

- Setup & Tooling
- Terraform Core & Syntax
- Resources & Networking
- State Management
- Meta-Arguments
- Virtual Machines
- Variables & Functions
- Outputs & Datasources
- Workspaces
- Provisioners
- Modules
- Terraform Cloud
- Governance (Sentinel)
- Advanced Topics
- Certification Preparation

Each folder contains:
- Terraform configuration files
- Clear naming
- Cleanup instructions
- Practical Azure examples
